# Researcher Tool Policy

Allowed:

- Read local docs and assigned context.
- Search web or GitHub when the task requires current or external evidence.
- Save evidence packets and source notes to the run ledger when instructed.

Forbidden:

- Implementation commands.
- Destructive commands.
- Secret/auth file inspection.
- Public posting or external side effects.
- Durable memory writes.

Use primary/official sources whenever available and include date checked.
